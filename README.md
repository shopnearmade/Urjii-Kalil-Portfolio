# Senior Capstone Portfolio

## Overview
This portfolio includes three projects I worked on during my time as a Computer Science student at the University of St. Thomas. Each project represents a different stage in my growth as a developer and reflects both the technical and problem-solving skills I gained throughout the program. Links to each repository are included below, along with a short explanation of why I chose each project
  

---

## Project 1: Java Simple Logistics
**Repository:** [https://github.com/shopnearmade/logistics-api](https://github.com/shopnearmade/logistics-api)

**Why I chose this project:** 
I originally built this project as a simple MVP for a cottage food delivery business idea. At first, the application was written using a different framework and programming language. Later, after learning more about software architecture and the MVC (Model, View, Controller) pattern in my CISC 480 course, I decided to refactor the project into a cleaner and more organized structure. I also participated in the gALPHA St. Thomas 2026 Cohort, where I learned more about entrepreneurship and business strategy, which helped me improve the application based on more realistic business needs.
 
**Connection to the St. Thomas Mission:** 
This project connects to the St. Thomas mission of using knowledge and skills to contribute to the community. I wanted to build something that could support small local businesses and make delivery management more organized and efficient. It allowed me to combine software development with a practical business idea that could help people in the local community.

## Project 2: Full Stack Web App (Restaurant API)
**Repository:** [https://github.com/shopnearmade/restaurant-api](https://github.com/shopnearmade/restaurant-api)

**Why I chose this project:** 
This project was completed as a group project for my CISC 375 Web Development course. Our team built a full-stack restaurant application that included both a REST API backend and a frontend interface. My main contributions were building the order-related endpoints and implementing user authentication and authorization using JWT (JSON Web Tokens). Working on this project helped me improve both my backend development skills and my ability to collaborate with a team.
 

**Connection to the St. Thomas Mission:** 
The St. Thomas Convictions emphasize creating a caring culture and respecting the dignity and diverse contributions of every person. Working on this team brought these values of collaboration to life for me. I learned how to communicate effectively, share the workload, and integrate diverse perspectives into one solid product. Furthermore, building tools to help small restaurants run securely and efficiently allows us to use our technical skills to support local business owners and the common good.

## Project 3: Enterprise AWS Infrastructure as Code (Nearmade)
**Repository:** [https://github.com/shopnearmade/nearmade-infrastructure](https://github.com/shopnearmade/nearmade-infrastructure)

**Why I chose this project:** 
This is the most advanced project I have worked on recently. I wanted to learn more about cloud computing, enterprise infrastructure, and deployment automation. Using AWS CDK with Java, I built cloud infrastructure that included a Virtual Private Cloud (VPC), CI/CD deployment pipelines using CodePipeline, and secure AWS PrivateLink endpoints. Through this project, I gained a better understanding of how modern cloud systems are designed, deployed, and secured.

**Connection to the St. Thomas Mission:** 
Reflecting on the recent Canvas cyberattack in May 2026, I realized even more how important system security and reliability are to our daily lives. This incident highlighted the deep ethical responsibility we have to protect user data. By proactively building highly available and strictly isolated cloud infrastructure, I am practicing the "morally responsible leadership" that St. Thomas instills in us. It reflects my commitment to "think critically" about system vulnerabilities and "act wisely" to ensure that the digital systems people rely on for education and business areecure, and resilient against external threats.
